# Purpose
This folder includes files generated by automated scripts, used for e-mailing data,
displaying or visualizing purposes.

| Folder | Contents |
| --- | --- |
| `alphaspread/` | AlphaSpread valuations: `nasdaq100_valuations.json`, `sp500_valuations.json` (latest run) and dated HTML + PNG charts in `nasdaq/` and `sp500/`. |
| `fairvalue/` | Fair Value valuations from `fairvalue/`: `nasdaq100_valuations.json`, `sp500_valuations.json` (latest run) and dated JSON in `nasdaq/` and `sp500/`. |
| `macro/` | Liquidity-stress snapshots. |
| `sp500_weights.json` | Market caps, shared by both sources for the cap-weighted averages. |
