loan.json format

The file must be valid JSON with this structure:

{
  "total": 109000,               // required: original loan amount (€)
  "interest_rate": 3.97,         // optional: global annual interest rate (%); used as fallback
  "monthly_installment": 454.17, // optional: fixed monthly installment (€)
  "history": [
    {
      "date":          "2022-05-02", // YYYY-MM-DD
      "principal":     454.17,       // principal paid in this transaction (€)
      "interest":       47.24,       // interest paid in this transaction (€)
      "cost":             2.50       // bank fees / other costs (€)
    },
    {
      "date":          "2024-01-01",
      "principal":     454.17,
      "interest":       52.10,
      "cost":             2.50,
      "interest_rate":    4.50  // optional: rate changed; overrides global for projections
    }
  ]
}
FieldTypeDescription
totalnumberRequired. The original total principal of the loan in €.
interest_ratenumberGlobal annual interest rate in percent (3.97 = 3.97%). Used when no entry-level rate is set.
monthly_installmentnumberFixed monthly installment in €. Used as the minimum payment in simulations.
history[].datestringTransaction date as YYYY-MM-DD. Transactions in the same calendar month are combined.
history[].principalnumberPrincipal repaid in this transaction (€). Record extra lump-sum payments here.
history[].interestnumberInterest paid in this transaction (€). Use 0 for extra lump-sum principal payments.
history[].costnumberBank fees or transaction costs (€). Use 0 if none.
history[].interest_ratenumberOptional. Annual rate in effect for this transaction (%). The most recent entry with a rate overrides the global rate for upcoming-interest projections, which suits variable-rate mortgages.
Your file is sent only to the backend for analysis and is not stored. Nothing here is financial advice.
