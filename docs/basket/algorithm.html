Reproduce

    

      
From the basket/ folder, publish a new run for these pages. It reads config.yaml and reuses the yfinance cache:

      
PYTHONPATH=src python3 -m mrscore.cli.export_web
# or another config / output folder
./web.sh export   # same thing, writing into this site's docs/basket/data

      
Then run ./web.sh start to preview it, and ./web.sh publish to commit and push it to this site. Each export adds a run to the picker; the newest is shown by default.
